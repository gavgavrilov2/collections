# Contributing

## Как внести вклад

1. Fork репозитория
2. Создайте отдельную ветку для ваших изменений
3. Внесите изменения
4. Проверьте работу плагина
5. Создайте Pull Request

## Проверка изменений

### Обязательно
- Проверьте работу на PC
- Проверьте работу на Mobile
- Убедитесь, что существующие функции не сломаны

### Если изменение касается TV
- Проверьте работу на Android TV (или эмуляторе)
- Проверьте навигацию пультом (D-pad)
- Проверьте focus-навигацию
- Проверьте все TV scale размеры (Компактный, Обычный, Крупный, Очень крупный)

### Если изменение касается карточек
- Проверьте portrait карточки
- Проверьте landscape карточки
- Проверьте progress bar
- Проверьте badge рейтинга

### Если изменение касается коллекций
- Проверьте добавление в коллекцию
- Проверьте удаление из коллекции
- Проверьте создание новой коллекции
- Проверьте удаление коллекции

## Код-стайл

- JavaScript: IIFE обёртка, `'use strict'`
- CSS: BEM-подобная номенклатура (`mc-block__element--modifier`)
- CSS custom properties для динамических значений
- Комментарии только при необходимости

## Pull Request

- Опишите что было сделано и почему
- Укажите какие платформы проверены
- Приведите скриншоты/записи экрана, если изменение заметно визуально
