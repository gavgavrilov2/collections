# Lampa — Мои Коллекции

> Кастомный плагин для Lampa, расширяющий стандартную работу с коллекциями фильмов, сериалов и анимации и предоставляющий отдельный интерфейс «Мои Коллекции».

> Это независимый кастомный/community-проект для Lampa. Проект не является официальным продуктом или официальным плагином Lampa.

## О проекте

«Мои Коллекции» — это кастомный интерфейс для управления сохранённым медиаконтентом внутри Lampa.

Пользователь может организовывать контент по категориям, сохранять фильмы и сериалы в коллекции, отмечать просмотренное, добавлять контент в список просмотра и работать с избранным.

Проект ориентирован не только на ПК, но и на использование на телевизорах и других устройствах, где важны крупный интерфейс и управление через пульт.

## Возможности

- Система коллекций с возможностью создания пользовательских списков
- Встроенные коллекции: Посмотрел, Буду смотреть, Хочу посмотреть, Потом, Избранное
- Категории: Все, Фильмы, Сериалы, Мультфильмы, Избранное
- Продолжение просмотра с индикатором прогресса
- Недавно добавленные
- Недавно просмотренные
- Фильтрация по коллекциям
- Открытие штатной карточки Lampa
- Отслеживание прогресса просмотра (время, продолжительность, серия, сезон)
- Добавление/удаление фильмов и сериалов из коллекций
- Кнопка коллекции на странице фильма с визуальной индикацией
- Уведомления при操作ациях с коллекциями
- Адаптивный пользовательский интерфейс

## Категории

### Все
Показывает весь сохранённый контент из всех коллекций.

### Фильмы
Показывает обычные фильмы (без анимации).

### Сериалы
Показывает обычные сериалы (без анимации).

### Мультфильмы
Показывает анимацию, мультфильмы и соответствующий контент, определяемый системой как Animation (жанр ID 16 или жанр "animation"/"анимация").

### Избранное
Показывает контент, добавленный в коллекцию «Избранное».

## TV-режим

Интерфейс рассчитан на использование на больших экранах телевизоров.

Возможности TV-режима:
- Управление с помощью пульта (D-pad навигация)
- Focus-навигация по вкладкам, карточкам и кнопкам
- Адаптивная сетка карточек (4-8 колонок в зависимости от ширины экрана)
- Вертикальная и горизонтальная прокрутка
- Выбор размера интерфейса

### Размеры интерфейса

| Название | Масштаб |
|---|---|
| Компактный | 0.85 |
| Обычный | 1.0 |
| Крупный | 1.15 (по умолчанию) |
| Очень крупный | 1.3 |

Настройка размера интерфейса доступна только в TV-режиме и сохраняется между сессиями.

## Установка

1. Откройте Lampa
2. Перейдите в Настройки → Плагины
3. Вставьте URL плагина:
   ```
   https://gavgavrilov2.github.io/collections/collections.js
   ```
4. Нажмите Установить
5. Перезапустите Lampa
6. В боковом меню появится пункт «Мои Коллекции»

## Обновление

Плагин обновляется автоматически при перезапуске Lampa, так как загружается по URL. При доступности новой версии она подтянится автоматически.

Данные коллекций хранятся в localStorage и не удаляются при обновлении плагина.

## Настройки

### Размер интерфейса на TV

Доступен в TV-режиме через кнопку масштаба на главной странице плагина.

- Компактный — уменьшенные элементы
- Обычный — стандартный размер
- Крупный — увеличенные элементы (по умолчанию)
- Очень крупный — максимальный размер

Настройка сохраняется в localStorage и применяется автоматически при следующем запуске.
