# Changelog

## Unreleased

### Added
- Выделенный файл `collections.css` для стилей плагина
- Загрузка CSS через `<link>` тег с fallback

### Changed
- CSS вынесен из JavaScript в отдельный файл
- Стили управляются через CSS custom properties (`--mc-s`, `--mc-cw`, `--mc-ch`, `--mc-lw`, `--mc-lh`, `--mc-gap`)
- TV-стили применяются через класс `.mc-root.tv` вместо条件ного генерирования

## v2.1.1

### Added
- Система категорий: Все, Фильмы, Сериалы, Мультфильмы, Избранное
- Эксклюзивная категория мультфильмов (анимация определяется как отдельная категория)
- TV scale: выбор размера интерфейса (Компактный, Обычный, Крупный, Очень крупный)
- Адаптивный размер карточек на TV (4-8 колонок в зависимости от ширины экрана)
- Нормализация сохранённых данных фильмов (`normalizeSavedMovie`)
- Продолжение просмотра с индикатором прогресса и оставшимися минутами
- Недавно добавленные (до 20)
- Недавно просмотренные (до 20)
- Фильтрация по коллекциям
- Кнопка коллекции на странице фильма
- Уведомления при操作ациях с коллекциями

### Improved
- Определение анимации: проверка genre_ids (ID 16) и genres (name "animation"/"анимация")
- Определение медиа типа: media_type, type, number_of_seasons, number_of_episodes, first_air_date
- TV навигация: focus-навигация по всем элементам
- Адаптивность: корректные размеры на различных экранах
- Dual-storage: localStorage + Lampa.Storage с fallback

### Fixed
- Исключение мультфильмов из категорий Фильмы и Сериалы
- Определение категории cartoon для анимации
- Нормализация category/media_type/subtype при чтении данных
- TV controller registration для навигации
- TV scale влияет на размеры карточек
